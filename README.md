# WW4-Tools

Tools associated with the WAVEWATCH IV (WW4) repository. Some of the tools can be used for WAVEWATCH III too.

Documentation is maintained in the [WW4-Tools wiki](https://github.com/NOAA-EMC/WW4-Tools/wiki). The wiki is still being set up.

See also [AGENTS.md](./AGENTS.md), [CONTRIBUTORS.md](./CONTRIBUTORS.md), [INTENT.md](./INTENT.md) and [LICENSE.md](./LICENSE.md).
